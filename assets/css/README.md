# assets/css/

Stylesheet for the site.

| File | Notes |
|------|-------|
| `style.css` | All styling, linked from `index.html`. Theming runs on CSS custom properties (`--ink`, `--paper`, `--muted`, …) redefined under `:root[data-theme="dark"]`; the renderer only ever flips the `data-theme` attribute. |
